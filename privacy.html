개인정보처리방침

「신비한 방사선 업로더」 · 시행일 2026. 11. 11.

1. 앱의 목적

「신비한 방사선 업로더」(Google Cloud 프로젝트 radiation-channel-yt)는 유튜브 채널 「신비한 방사선」 운영자가 자기 채널에 영상을 올리고 예약하며, 영상 정보·썸네일을 고치고, 채널 통계를 확인하려고 만든 개인용 프로그램입니다. 일반 사용자에게 공개하거나 배포하지 않습니다.

2. 받는 정보의 범위

  • 운영자 본인 채널의 YouTube 데이터만 받습니다. 쓰는 권한은 영상 업로드(youtube.upload), 영상 정보·썸네일 수정과 조회(youtube), 채널 분석 보고서 조회(yt-analytics.readonly)입니다.
  • 다른 사람의 개인정보는 모으지 않습니다. 시청자 개인을 식별하는 정보는 받지 않으며, 통계는 YouTube가 주는 집계 수치만 씁니다.

3. 쓰는 곳

  • 운영자 채널의 영상 업로드·공개 예약·영상 정보 수정
  • 운영자가 채널 운영을 점검하는 성과 표(편별 조회수·시청 시간·노출수 등) 작성

4. 보관

로그인 허가 정보(토큰)와 받은 통계는 운영자 본인 컴퓨터 안에만 저장하며, 외부 서버로 보내지 않습니다.

5. 제3자 제공

받은 정보를 제3자에게 팔거나 제공하지 않으며, 광고에 쓰지 않습니다.

6. Google API 데이터 정책 준수

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy를 따르며, 제한적 사용(Limited Use) 요건을 포함합니다.

7. 권한 철회

언제든 Google 계정 → 보안 → 서드 파티 액세스(서드 파티 앱 및 서비스)에서 「신비한 방사선 업로더」의 권한을 삭제할 수 있습니다. 삭제하면 저장된 토큰은 더 이상 쓸 수 없습니다.

8. 문의

유튜브 채널 「신비한 방사선」의 정보 페이지를 통해 문의할 수 있습니다.

Privacy Policy (English summary)

“신비한 방사선 업로더” is a private tool used only by the owner of the YouTube channel “신비한 방사선” to upload and schedule videos, edit video metadata and thumbnails, and read aggregate analytics for that channel. It requests the youtube.upload, youtube and yt-analytics.readonly scopes for the owner’s own channel only and does not collect personal data of other people. OAuth tokens and reports are stored only on the owner’s computer. Data is never sold, shared with third parties or used for advertising. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from Google Account → Security → Third-party access. Effective date: 2026-11-11.
